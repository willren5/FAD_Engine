# Security reports

For a sensitive issue, use GitHub private vulnerability reporting if it is enabled
for this repository. Otherwise email [fad@fadrecords.com](mailto:fad@fadrecords.com) to arrange a private report.

Do not place credentials, signing keys, private account state, commercial user
data or an unredacted product crash dump in a public issue. Include the affected
source version, platform, input bounds and a minimal self-generated reproduction.

The Core is independent of product accounts and commerce. A problem in a
downstream product should identify that boundary rather than posting its private
implementation here. This project makes no response-time or support guarantee.
